# Academic Personal Website

This is a static academic homepage for a Computer Science PhD student.

## Edit Your Details

- Update name, affiliation, advisor, office, and email in `index.html`.
- Replace placeholder links for CV, Google Scholar, GitHub, papers, code, and slides.
- Swap `assets/research-banner.png` with a portrait or research image if desired.
- Edit publications, projects, teaching, and news directly in `index.html`.
- The visitor map uses ClustrMaps. Replace `REPLACE_WITH_YOUR_CLUSTRMAPS_ID`
  in `index.html` with the `d=` value from your own ClustrMaps embed code.

## Preview

Open `index.html` in a browser. No build step is required.
